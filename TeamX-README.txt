1. 프로젝트 소개

PaperShare는 스터디 그룹별로 논문을 모으고, 읽기 상태와 메모를 공유하는 웹 애플리케이션이다.
Phase 3의 JDBC 기능을 JSP로 옮겼으며, Phase 2의 Oracle 스키마와 샘플 데이터를 사용한다.
그룹원은 논문별로 하이라이트와 댓글·답글을 남기고 그룹의 읽기 기록을 조회할 수 있다.

2. 실행 환경과 포함 파일

- Java JDK 25, Apache Tomcat 11.0.29, Oracle 19c
- sql/Team4-Phase2-1.sql은 테이블 9개와 시퀀스 3개를 생성한다.
- sql/Team4-Phase2-2.sql은 샘플 데이터 624행을 삽입하고 커밋한다.

3. 데이터베이스 초기화

압축을 푼 프로젝트 폴더에서 Oracle에 접속한 뒤 아래 두 파일을 순서대로 실행한다.

  sql/Team4-Phase2-1.sql
  sql/Team4-Phase2-2.sql

Tomcat에 아래 환경 변수를 설정한다.

  DB_URL       JDBC 접속 URL (예: jdbc:oracle:thin:@//127.0.0.1:1522/XE)
  DB_USER      Oracle 계정명
  DB_PASSWORD  해당 계정의 비밀번호

4. 웹 서버 실행

4. IntelliJ IDEA에서 실행

1) 프로젝트 폴더를 열고 Project SDK에 JDK 25를 지정한다.
2) Tomcat - phase4 실행 구성에서 로컬 Tomcat 11을 선택한다.
3) Deployment에서 phase4:war exploded 아티팩트와 /phase4 컨텍스트 경로를 확인한다.
4) 실행 구성의 환경 변수에 DB_URL, DB_USER, DB_PASSWORD를 지정하고 실행한다.
5) 브라우저에서 http://127.0.0.1:8082/phase4/ 로 접속한다.

5. 사용 방법과 주요 기능

처음 접속하면 샘플 사용자 ID 1로 시작한다. 02번에서 가입 그룹을 확인하고, 03번에서 그룹 ID 5를 선택하면 07번에서 샘플 논문과 그룹 메모를 볼 수 있다.
워크스페이스의 '논문 선택하고 리뷰하기'를 눌러 논문을 고르면 논문 상세 정보와 리뷰 기능이 열린다.

- 01~03 사용자 전환, 내 그룹 조회, 현재 그룹 변경
- 04~06 그룹 생성, 그룹 가입, 현재 그룹원 조회. 그룹을 만들면 생성자는 리더로 등록된다.
- 07~09 그룹 논문·메모 조회, 새 논문과 그룹 메모 등록, 기존 논문을 현재 그룹에 추가
- 10~11 논문 태그 추가, 그룹 메모·읽기 상태 변경(읽음, 리뷰중, 완료)
- 12~14 페이지와 위치를 지정해 하이라이트 생성, 하이라이트·댓글 조회, 댓글·답글 작성
- 15~16 본인 댓글 수정·삭제. 답글이 있는 댓글은 답글을 유지하고 본문을 삭제 표시로 바꾼다.
- 17 Phase 2 검색 쿼리 10개 실행. 연도·제목, 그룹 리더, 완료 논문, 평균 연도, 답글, 태그,
  그룹 논문 수, 하이라이트, 댓글 통계, 하이라이트와 댓글을 모두 작성한 사용자 등을 조회한다.
